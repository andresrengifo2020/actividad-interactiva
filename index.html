IF / ELSE Programs

A program can make a decision.

INPUT → VARIABLE → IF → ELSE → OUTPUT

The computer checks a condition. If the condition is TRUE, it does one thing. If the condition is FALSE, it does something else.

▮ Quick Guide

DECLARE
Creates a variable.
DECLARE age AS INTEGER
INPUT
Gets information from the user.
INPUT age
OUTPUT
Displays information.
OUTPUT "Hello"
IF / ELSE
Makes a decision.
IF age >= 13 THEN
